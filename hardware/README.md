# Hardware — earlier revision (archived)

The Eagle design files in this folder (`pc_pulse Express.sch`,
`pc_pulse Express.brd`, `pc_pulse express_schematic.pdf`) are an earlier
revision of the ProtoCentral Pulse Express board.

They are kept here permanently so that existing links, forks, and references to
these files continue to work. They are no longer the current design.

## Current design files

Revision **v3** and everything that follows it live in a dedicated hardware
repository, as a KiCad project:

**https://github.com/Protocentral/protocentral_pulse_express_hardware**
